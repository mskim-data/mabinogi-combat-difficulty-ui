# Mabinogi Mobile Combat Difficulty UI

## 1. 프로젝트 개요

마비노기 모바일 전투 콘텐츠 진입 전, 유저가 자신의 전투력을 입력하고 난이도별 권장 전투력과 보상 효율을 비교할 수 있는 Unity UI 프로토타입입니다.

유저는 보통, 어려움, 매우 어려움, 지옥, 악몽, 키홀 난이도 중 하나를 선택할 수 있으며, 선택한 난이도의 권장 전투력, 예상 보상, 예상 클리어 시간, 보상 효율을 확인할 수 있습니다.

입력한 전투력을 기준으로 클리어 가능성을 판단하고, 현재 전투력에서 클리어 가능한 난이도 중 보상 효율이 가장 높은 난이도를 추천합니다.

## 2. 개발 배경

마비노기 모바일 플레이 경험을 바탕으로, 전투 콘텐츠 진입 전 유저가 전투력과 보상 효율을 함께 고려해야 한다는 점에 착안했습니다.

전투 콘텐츠는 단순히 높은 난이도를 선택하는 것이 아니라, 현재 전투력으로 클리어 가능한지, 클리어 시간 대비 보상이 적절한지, 다음 목표 난이도까지 얼마나 부족한지를 함께 판단해야 합니다.

이에 따라 본 프로젝트에서는 전투력 입력값을 기준으로 난이도별 권장 전투력, 보상 효율, 클리어 가능성, 추천 난이도를 한 화면에서 확인할 수 있는 UI 프로토타입을 구현했습니다.

## 4. 주요 기능

### 난이도 선택

- 보통, 어려움, 매우 어려움, 지옥, 악몽, 키홀 6개 난이도 버튼을 제공합니다.
- 버튼 클릭 시 선택한 난이도의 상세 정보가 표시됩니다.
- 선택한 난이도 버튼은 색상으로 강조됩니다.

### 난이도 정보 표시

선택한 난이도에 대해 아래 정보를 표시합니다.

- 권장 전투력
- 예상 보상
- 예상 클리어 시간
- 보상 효율
- 보상 효율 계산 기준

### 전투력 입력 및 검증

- `TMP_InputField`를 통해 유저 전투력을 입력받습니다.
- 빈 입력값과 숫자가 아닌 입력값을 예외 처리합니다.
- 숫자가 아닌 값이 들어와도 프로그램이 멈추지 않도록 `int.TryParse()`를 사용했습니다.

### 클리어 가능성 판단

입력한 전투력과 선택한 난이도의 권장 전투력을 비교해 다음 상태를 표시합니다.

- 안정적으로 클리어 가능
- 적정 난이도
- 도전 가능하지만 파티 플레이 권장
- 전투력 부족

### 추천 난이도 계산

- 현재 전투력으로 클리어 가능한 난이도만 후보로 선정합니다.
- 후보 난이도 중 보상 효율이 가장 높은 난이도를 추천합니다.
- 추천 난이도의 권장 전투력 충족 여부, 보상 효율, 다음 목표 난이도까지 필요한 전투력 차이를 함께 표시합니다.

### 초기화 기능

- Reset 버튼으로 전투력 입력값, 난이도 정보, 판단 결과, 추천 결과, 선택 버튼 강조 상태를 초기화합니다.

## 7. 핵심 로직
1) 난이도 데이터 관리
public class DifficultyData
{
    public string difficultyName;
    public int requiredPower;
    public string rewardText;
    public int expectedClearTime;
    public int rewardScore;
}

2) 보상 효율 계산
보상 효율 = 보상 점수 / 예상 클리어 시간

3) 클리어 가능성 판단
전투력 차이 = 유저 전투력 - 선택 난이도 권장 전투력

전투력 차이 | 판단 결과
+ 5000 이상 | 안정적으로 클리어 가능
0 이상 | 적정 난이도
- 5000 이상 | 도전 가능하지만 파티 플레이 권장
- 5000 미만 | 전투력 부족

4) 추천 난이도 산정
추천 난이도는 다음 순서로 산정했습니다.
- 유저 전투력을 숫자로 변환할 수 있는지 확인합니다.
- 유저 전투력이 권장 전투력 이상인 난이도만 후보로 선정합니다.
- 후보 난이도 중 보상 효율이 가장 높은 난이도를 선택합니다.
- 현재 전투력으로 도전하지 못하는 다음 난이도가 있으면 필요한 전투력 차이를 함께 표시합니다.

80,000 | 키홀 | 키홀 추천, 모든 난이도 권장 전투력 충족
빈칸 | 보통 | 전투력을 입력해주세요

## 9. 실행 방법
1) Unity Hub에서 프로젝트를 엽니다.
2) Assets/Scenes/MainScene.unity를 실행합니다.
3) Game View에서 전투력을 입력합니다.
4) 난이도 버튼을 클릭합니다.
5) 선택 난이도 정보, 판단 결과, 추천 난이도를 확인합니다.

## 10. 개발 과정에서 해결한 문제
| 문제 | 원인 | 해결 |
|---|---|---|
| TextMeshPro 한글 깨짐 | 기본 TMP Font Asset에 한글 글리프 없음 | 한글 지원 폰트로 TMP Font Asset 생성 |
| 특정 한글 글자 누락 경고 | Font Asset에 일부 글자 미포함 | Dynamic Font Asset 설정 또는 필요한 문자 추가 |
| Debug 모호성 오류 | UnityEngine.Debug와 System.Diagnostics.Debug 충돌 | UnityEngine.Debug.Log()로 명시 |
| Inspector에 필드가 안 보임 | public 변수 누락 또는 컴파일 에러 | public 필드 선언 및 Console Error 해결 |
| 버튼 연결 누락 시 NullReference 가능성 | Inspector에서 Button 연결 누락 | public Button 필드 연결 상태 점검 |
| 문자 입력 시 오류 가능성 | 입력값을 바로 int로 변환할 경우 예외 발생 | int.TryParse()로 입력값 검증 |
