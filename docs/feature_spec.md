# 기능 명세서: 마비노기 모바일 전투 콘텐츠 난이도 추천 UI 프로토타입

## 1. 문제 정의

전투 콘텐츠를 선택할 때 유저는 자신의 전투력, 콘텐츠별 권장 전투력, 예상 보상, 예상 클리어 시간을 함께 고려해야 한다.

그러나 이 정보가 분리되어 있거나 난이도별 비교가 어렵다면, 유저는 현재 스펙에서 어떤 난이도를 선택해야 하는지 판단하기 어렵다.

본 프로젝트에서는 전투력 입력값을 기준으로 난이도별 클리어 가능성과 보상 효율을 함께 보여주고, 현재 전투력에서 가장 적합한 난이도를 추천하는 UI 프로토타입을 구현한다.

## 2. 프로젝트 목표

- 유저가 자신의 전투력을 입력할 수 있다.
- 유저가 전투 콘텐츠 난이도를 선택할 수 있다.
- 선택한 난이도의 권장 전투력, 예상 보상, 예상 클리어 시간, 보상 효율을 확인할 수 있다.
- 입력한 전투력과 선택한 난이도의 권장 전투력을 비교해 클리어 가능성을 판단한다.
- 현재 전투력으로 클리어 가능한 난이도 중 보상 효율이 가장 높은 난이도를 추천한다.
- 추천 난이도와 추천 사유를 함께 표시한다.
- Reset 버튼으로 입력값과 UI 상태를 초기화할 수 있다.

## 3. 사용자 시나리오

### 기본 시나리오

1. 유저가 자신의 전투력을 입력한다.
2. 난이도 버튼 중 하나를 선택한다.
3. 선택한 난이도의 상세 정보가 표시된다.
4. 현재 전투력 기준 클리어 가능성이 표시된다.
5. 클리어 가능한 난이도 중 보상 효율이 가장 높은 난이도가 추천된다.
6. 추천 사유와 다음 목표 난이도가 표시된다.

### 예외 시나리오

1. 유저가 전투력을 입력하지 않고 난이도를 선택한다.
2. 시스템은 전투력을 입력하라는 메시지를 표시한다.

1. 유저가 숫자가 아닌 값을 입력한다.
2. 시스템은 숫자만 입력하라는 메시지를 표시한다.

1. 유저가 Reset 버튼을 클릭한다.
2. 입력값, 난이도 정보, 판단 결과, 추천 결과, 선택 버튼 강조 상태가 초기화된다.

## 4. 기능 요구사항

| ID | 기능 | 설명 |
|---|---|---|
| F-01 | 난이도 선택 | 보통, 어려움, 매우 어려움, 지옥, 악몽, 키홀 6개 난이도 버튼을 제공한다. |
| F-02 | 난이도 정보 출력 | 선택한 난이도의 권장 전투력, 예상 보상, 예상 클리어 시간, 보상 효율, 효율 기준을 표시한다. |
| F-03 | 전투력 입력 | TMP_InputField를 통해 유저 전투력을 입력받는다. |
| F-04 | 입력값 검증 | 빈 입력값과 숫자가 아닌 입력값을 예외 처리한다. |
| F-05 | 클리어 가능성 판단 | 유저 전투력과 선택 난이도의 권장 전투력을 비교해 상태 메시지를 출력한다. |
| F-06 | 추천 난이도 계산 | 클리어 가능한 난이도 중 보상 효율이 가장 높은 난이도를 추천한다. |
| F-07 | 추천 사유 표시 | 추천 난이도의 권장 전투력 충족 여부, 보상 효율, 다음 목표 난이도를 표시한다. |
| F-08 | 선택 버튼 강조 | 현재 선택한 난이도 버튼의 색상을 변경한다. |
| F-09 | 초기화 | Reset 버튼으로 입력값, 출력 텍스트, 버튼 강조 상태를 초기화한다. |

## 5. 난이도 데이터 정의

| 난이도 | 권장 전투력 | 예상 보상 | 예상 클리어 시간 | 보상 점수 |
|---|---:|---|---:|---:|
| 보통 | 30,000 | 기본 보상 | 5분 | 50 |
| 어려움 | 45,000 | 중급 보상 | 7분 | 75 |
| 매우 어려움 | 55,000 | 상급 보상 | 9분 | 95 |
| 지옥 | 60,000 | 고급 보상 | 10분 | 110 |
| 악몽 | 68,000 | 희귀 재료 보상 | 13분 | 145 |
| 키홀 | 75,000 | 최상급 보상 | 16분 | 180 |

## 6. 입력값 검증 기준

| 입력값 | 처리 |
|---|---|
| 빈 값 | “내 전투력을 입력해주세요.” 메시지 표시 |
| 숫자가 아닌 값 | “전투력은 숫자만 입력해주세요.” 메시지 표시 |
| 정상 숫자 | int.TryParse로 정수 변환 후 판단 로직 실행 |

입력값 검증은 `TryGetUserPower()`에서 처리한다.

## 7. 클리어 가능성 판단 기준

유저 전투력과 선택 난이도의 권장 전투력 차이를 기준으로 판단한다.

전투력 차이 = 유저 전투력 - 선택 난이도 권장 전투력
